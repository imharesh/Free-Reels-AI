## Prerequisites

- [Docker](https://docs.docker.com/get-docker/) and Docker Compose (recommended)
- Or: Node.js 22+, [pnpm](https://pnpm.io/installation), and ffprobe (for local dev)

## Clone the repository

```bash
git clone https://github.com/imharesh/FreeReelAI.git
cd FreeReelAI
```

## Set up environment variables

Copy the example env file and fill in your API keys. See [API Keys](/docs/getting-started/api-keys) for details on which keys you need.

```bash
cp .env.example .env
```

Open `.env` and add keys only for hosted services you plan to use. For a local LLM, use Ollama as an OpenAI-compatible endpoint; Kokoro provides local voice synthesis without a TTS API key.

## Docker Compose (recommended)

This starts Redis, the API server, and the background worker. The web UI is available at `http://localhost:3000`.

```bash
docker compose up
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Type a topic, pick your providers, and hit **Generate**. See the [Web UI guide](/docs/getting-started/web-ui) for a walkthrough.

### Docker CLI (single run)

If you just want to render one video without the web UI:

```bash
docker run --env-file .env --shm-size=2gb -v ./output:/output \
  ghcr.io/imharesh/freereelai "5 stoic lessons that changed my life"
```

Or through Docker Compose:

```bash
docker compose run worker npx tsx src/index.ts --yes "5 stoic lessons that changed my life"
```

The `--yes` flag auto-confirms the cost estimation prompt, which is required in non-interactive environments like Docker.

## Local development

Install dependencies and run the pipeline directly:

```bash
pnpm install
```

```bash
# Full pipeline with Google providers (LLM, image, TTS, video, music)
pnpm start "the fall of the Roman Empire" --provider google

# Free local TTS, no API spend on voiceover
pnpm start "5 stoic lessons" --provider local

# Dry run — outputs the DirectorScore JSON without generating any assets
pnpm start "your topic" --dry-run

# Creative direction — guide the AI with a brief
pnpm start "deep sea exploration" --direction examples/direction-brief.md

# Replay — reuse a previous score, re-render with different config
pnpm start "your topic" --score output/2026-04-10-.../score.json
```

See [CLI Usage](/docs/getting-started/cli) for all available flags.

## Use a local Ollama model

Install [Ollama](https://ollama.com/download) on the host machine, then download a model:

```powershell
ollama pull gemma4:e2b
```

In the web app's **Advanced** settings, set **LLM Provider** to **Custom (OpenAI-compatible)**, enter `gemma4:e2b` as the model ID, and set the Base URL:

- `http://localhost:11434/v1` when running Free Reels AI directly on the host
- `http://host.docker.internal:11434/v1` when using Docker Desktop on Windows or macOS

Choose **None** for Search Provider unless you configure an external search service. Select **Kokoro (Local)** for voice and **Bundled (Free)** for music. Local Ollama does not need an API key.

Ollama's server may need to accept connections from Docker containers. If you change its bind address, keep access limited to trusted local/container traffic and do not expose the Ollama port to the public internet. Local text and voice reduce API charges, but the current AI image and video providers are hosted services; use stock media when suitable and review the cost estimate before starting a render.

## What happens next

Once you submit a topic, the pipeline runs through these stages:

1. **Research** — Web search grounds the script in real facts
2. **Director** — Writes a short-form script with scene breakdowns and visual direction
3. **Voiceover** — Generates TTS audio with word-level timestamps
4. **Visuals** — AI images, AI video clips, and stock footage
5. **Music** — AI-generated or bundled background score
6. **Assembly** — Composites everything into a vertical MP4 via Remotion
7. **Critic** — AI scores the output; re-runs if quality is below threshold

The final MP4 lands in the `./output` directory (CLI) or is downloadable from the web UI.
